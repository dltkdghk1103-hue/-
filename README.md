## 이번 변경 범위

노란색·초록색 제품의 원본 DXF 엔티티 4개에서 모든 꼭짓점 좌표, 원호 bulge, 폭, 열린/닫힌 상태가 동일함을 저장 후 확인했습니다. 원점과 단위도 원본 그대로입니다. 제품에 턱·홈·가이드·돌출부를 추가하지 않았습니다.

흰색 연결부의 상부 직선 두 개만 원호로 바꿨습니다. 연결 목은 양쪽 모두 원래 0.25 mm이며 접속 끝점과 하부 곡선은 유지했습니다. 새 연결부는 기존 흰색 영역 안에만 존재합니다.

연결부를 완전히 제거한 이후 제품 간 포개짐 조건은 원본과 같습니다. 잔여 연결부의 걸림, 완전 파단, 내부 배출과 금형 제작 가능성은 아직 검증하지 않았습니다. Rev B도 제작 확정 도면이 아닌 검토용 후보입니다.

보고서 1–6절은 원본 형상 분석, 7절은 이번 조건 정정과 Rev B의 제한적 탄성 비교입니다.
